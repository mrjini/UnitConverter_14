## 4. STEP 4 — GREEN 최소 구현 요약

### entity/unit.py

- `Unit` dataclass — `name`, `to_meter_factor`
- `ConversionResult` dataclass — `input_unit`, `input_value`, `target_unit`, `target_value`

### entity/registry.py

- `UnitRegistry` — `register`, `get`, `all_units`, `has`
- 등록 순서 보존 (`_order` 리스트)

### entity/converter.py

- `Converter.convert_all(unit, value, registry)` → `list[ConversionResult]`
- 변환 흐름: `meter_value = value × input.to_meter_factor` → `raw = meter_value / target.to_meter_factor` → display 1자리
- `_round_display()` — `Decimal` + `ROUND_HALF_UP` ([docs/spec/06-conversion-rules.md](../docs/spec/06-conversion-rules.md) §6)
- Registry 루프 기반 — **단위별 if/elif 없음**, feet↔yard 직접 상수 없음

### tests

- `tests/conftest.py` — `src/` 경로 등록 (import 지원)
- `test_conv_01_03_converter.py` — RED `pytest.fail` 제거, assert 본문 + 헬퍼 (`_make_default_registry`, `_to_dict`)

### ECB 준수

| 검사 | 결과 |
|------|------|
| entity → boundary/control/infrastructure import | **없음** ✓ |
| meter 경유 변환 | **준수** ✓ |
| 단위별 if/elif 금지 | **준수** ✓ |

### CONV-03 assert 보정

RED 설계표·주석의 `feet=8.2`는 README Golden 삼각(meter:2.5 ↔ feet:8.2 ↔ yard:2.7)을 그대로 옮긴 값이다. meter 경유 공식 적용 시 `yard:2.7` 입력의 feet display는 **8.1**이며, [09-scenario-catalog.md](../docs/spec/09-scenario-catalog.md) CONV-03 Then도 feet 값을 8.2로 고정하지 않는다. GREEN assert를 `feet=8.1`로 확정했다.
